English / Japanese patch

Complete build

Converts a verified Japanese installation into the current translated build. It includes the final script, glossary, menus, images, verified character portraits, text-hook support, and immediate full-game EN/JP switching. Version 1.0.4 captures one text command per advance and makes native Windows language-switch restarts reliable; it updates existing bilingual installs in place.

  1. Extract the archive beside a Japanese game folder or an existing patcher installation.
  2. Run Install BST English Patch.command on macOS or the .bat launcher on Windows.
  3. Drag the game folder into the prompt. Launch Bst.exe when it finishes.

BST text hooker

JP or EN

Captures dialogue, narration, and choices that ordinary text hookers miss. Version 1.0.2 reads the exact UTAGE command advanced on each click instead of returning the full page.

  1. The complete patch above already includes the game-side hook. For an untouched Japanese build, run install_game_hook.py once while the game is closed.
  2. Start the game, then run Run BST Text Hooker.command or Run BST Text Hooker.bat.
  3. Advance normally; captured lines appear in the terminal and clipboard.
Download text hooker Release notes
Compatibility and options

No BepInEx installation is needed. The hooker supports readable output, JSONL history, raw UTAGE markup, clipboard-free mode, and an explicit Player.log path.
